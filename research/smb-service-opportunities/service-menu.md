# Proposed service menu

Reviewed 2026-11-02. **Every customer-facing item below is a concept, not a delivered prototype.** Effort ranges are original planning estimates, not market statistics. Assumptions: one experienced builder, one supported CMS/static stack, client-approved copy/assets available, no major migration, one reviewer, one revision round. Effort is hands-on hours; waiting for access, approvals and DNS is additional elapsed time. Taxes, paid media, supplier/platform charges and data licensing are separate.

## Capped additions to an existing care account

Prices below assume one combined invoice and shared account overhead. Do not resell these as complete standalone services or charge twice for the same care-plan check. Base-plan and add-on minutes must be recorded separately; caps are incremental. If provider cost or support exceeds a cap, pause optional work and offer a scoped upgrade; never silently charge overages.

The first three recurring additions have inspectable obligations. A one-time file installation does not create a monthly customer benefit on its own. Google's guidance supports search fundamentals, not a promise that an `agents.txt` or `llms.txt` file will cause citations. Repository agent instructions, crawler access controls and optional documentation files have different purposes; the separate technical SEO research should verify each provider before implementing changes. [Official Google AI search guidance](https://developers.google.com/search/docs/appearance/ai-features)

Before an implementation quote: inspect platform/version and ownership; verify backup/export/recovery; specify included page/location/endpoint counts; agree on evidence and exclusions; account for accessibility, abuse protection and data handling; state delivery dependencies. Credentials and real inquiry records belong in approved private systems, never this public research repository.
