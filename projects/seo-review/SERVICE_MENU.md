# SEO and AI-search review deliverables

Use this menu to scope work with a business owner. It contains no market prices, traffic forecasts or guaranteed outcomes. Agree target, access, page/query sample, output destination, owner and exclusions first. Effort estimates are in [TOOLS_AND_LIFT.md](TOOLS_AND_LIFT.md).

| Service | Client receives | Completion evidence |
| --- | --- | --- |
| Website search-readiness review | Scoped technical/content/local/experience findings, top-five priorities and dependency-ordered backlog | Each finding has observation, source, owner, lift, validation and limits; coverage includes unknowns |
| Industry and keyword opportunity brief | One vertical/geography, buyer-intent map, dated query/competitor evidence and useful page plan | Numeric metrics have provenance; manual work is labeled qualitative; local-service and wholesale goals are separate |
| AI-search and agent usability review | Vendor access/control matrix, factual-content checks, optional browser usability assessment and bounded visibility baseline | Actual policies/settings or unknowns; sample conditions and citations recorded; optional files are not sold as ranking mechanisms |
| Website-build SEO specification | Page requirements, verified business facts, metadata/link/schema plan, G1–G7 gates and measurement definitions | Builder can implement and test each requirement; private staging and launch authorization remain explicit |
| Measurement and integration plan | Authorized-source baseline, event definitions, selected tool/API plan, permissions/data handling and effort | Clear source/metric definitions, access gaps, costs/quotas where verified and acceptance tests; no account connections made |
| Post-change verification review | Retest of agreed fixes, regression evidence and recommended next review | Before/after evidence at matching scope; separate implementation success from search/lead changes; no automated monitoring implied |

Implementation is a separate scoped engagement. A review does not include deployment, production edits, profile edits, search submissions, tracking installation, paid tools, outreach or ongoing monitoring. Work can be complete with documented evidence gaps; an unknown must never be presented as a passed test. Private client reports remain outside this public repository.
