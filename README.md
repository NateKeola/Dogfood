## Organization

- Keep research under `research/<topic>/`, with a short README and dated data snapshots.
- Keep unrelated projects separate; do not move existing projects here without direction.
- This repository is public. Store public-source research only; exclude credentials, private correspondence, work account data, meeting details, and personal trackers. Private projects require a separately approved destination.
