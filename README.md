## Organization

- Keep projects under `projects/<topic>/` and research under `research/<topic>/`, each with a short README. Use dated snapshots where useful.
- Link related notes using ordinary Markdown links; avoid duplicate indexes and unnecessary folders.
- Keep unrelated projects separate; do not move existing projects here without direction.
- This repository is public. Store public-source research and approved generic concepts only; exclude credentials, private conversations, work/customer data, meeting details, personal biographies, and private tracker links. Private projects require a separately approved destination.
